Developed at the [VAST Lab](/projects?filter=vastlab) in collaboration with **Arkenstone**, this project combines cross-polarized photogrammetry, 3D Gaussian Splatting reconstruction, a full-stack web catalog (**[gemscans.com](https://gemscans.com)**), and a Unity 6 virtual gallery to digitize and interactively inspect fine mineral specimens.

### Cross-Polarized Photogrammetry & Gaussian Splatting

Standard photogrammetry struggles with transparent crystals and specular mineral facets. To capture true internal structure and surface reflectivity:

- **Cross-Polarized Capture & Photogrammetry**: Multi-angle turntable capture processed through **RealityScan** alongside polarized lighting setups to preserve fine mineral geometry and color fidelity.
- **3D Gaussian Splatting Reconstruction**: Specimens are reconstructed with **Jawset PostShot** and **LichtFeld Studio** into `.spz`, `.ply`, and `.splat` representations that retain view-dependent specular highlights and translucent depth.

### GemScans Web Catalog (`gems_site`)

The **[gemscans.com](https://gemscans.com)** platform is built with **React 18**, **Vite**, **Tailwind CSS v4**, and **Supabase**:

- **In-Browser Gaussian Splat & glTF Viewer (`viewer.js`)**: Powered by **PlayCanvas** (`gsplat` and glTF container assets) with persistent browser Cache API storage (`gem-splat-cache`), automatic mobile/desktop tiering, and robust bounding-center framing.
- **Geographic Provenance & Chemistry Search**: Features an interactive **3D Globe** plotting specimen discovery locations worldwide and an interactive **Periodic Table** modal (`PeriodicTableModal`) for filtering minerals by chemical formula and constituent elements.
- **Private Vault & Model Conversion**: Supports Supabase-authenticated private vault collections alongside a client-side **Three.js** GLB/glTF converter (`Convert`).

### Unity 6 Virtual Gemstone Gallery (`Gemstone-Gallery`)

In companion repository **[VAST-Lab/Gemstone-Gallery](https://github.com/VAST-Lab/Gemstone-Gallery)**, a **Unity 6 (`6000.6.2f1`, URP)** 3D virtual gallery built on [`vast-volumetricvideo-renderer`](https://github.com/VAST-Lab/vast-volumetricvideo-renderer) and [`vast-metaverse-tools`](https://github.com/VAST-Lab/vast-metaverse-tools) dynamically fetches public catalog JSON and Supabase vault models via `GemScanGalleryLoader`, spawning `.spz` and `.ply` scans onto gallery pedestals within WebGPU splat memory budgets.
