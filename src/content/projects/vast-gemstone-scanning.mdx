Developed at the [VAST Lab](/projects?filter=vastlab) in collaboration with Arkenstone, this project combines cross-polarized photogrammetry, 3D Gaussian Splatting reconstruction, a full-stack web catalog ([gemscans.com](https://gemscans.com)), a Unity 6 virtual gallery, and a splat-to-Minecraft export toolchain to digitize and showcase fine mineral specimens.

### Cross-Polarized Photogrammetry & Gaussian Splatting

Standard photogrammetry struggles with transparent crystals and specular mineral facets. To capture true internal structure and surface reflectivity:

- Cross-Polarized Capture & Photogrammetry: Multi-angle turntable capture processed through RealityScan alongside polarized lighting setups preserves fine mineral geometry and color fidelity.
- 3D Gaussian Splatting Reconstruction: Specimens are reconstructed with Jawset PostShot and LichtFeld Studio into `.spz`, `.ply`, and `.splat` representations that retain view-dependent specular highlights and translucent depth.

### GemScans Web Catalog

The [gemscans.com](https://gemscans.com) platform ([gems_site](https://github.com/VAST-Lab/gems_site)) is built with React 18, Vite, Tailwind CSS v4, and Supabase:

- In-Browser Gaussian Splat & glTF Viewer: Powered by PlayCanvas with persistent browser Cache API storage, automatic mobile and desktop tiering, and robust bounding-center framing.
- Geographic Provenance & Chemistry Search: Features an interactive 3D globe plotting specimen discovery locations worldwide alongside a periodic table modal for filtering minerals by chemical formula and constituent elements.
- Private Vault & Model Conversion: Supports Supabase-authenticated private vault collections and a client-side Three.js GLB/glTF conversion tool.

### Unity 6 Virtual Gemstone Gallery

In companion repository [Gemstone-Gallery](https://github.com/VAST-Lab/Gemstone-Gallery), a Unity 6 virtual gallery built on [vast-volumetricvideo-renderer](https://github.com/VAST-Lab/vast-volumetricvideo-renderer) and VAST Lab's shared metaverse packages ([vast-metaverse-tools](https://github.com/VAST-Lab/vast-metaverse-tools) and [vast-metaverse-networking](https://github.com/VAST-Lab/vast-metaverse-networking)) dynamically fetches public catalog JSON and Supabase vault models, spawning `.spz` and `.ply` scans onto gallery pedestals within WebGPU splat memory budgets.

### Gaussian Splats & Scans in Minecraft

[splat2mc](https://github.com/VAST-Lab/splat2mc) is a Python pipeline that converts 3D Gaussian Splats and high-poly photogrammetry scans into playable Minecraft Bedrock Edition Add-On packs (with interactive Gem Catalog menus and in-game commands) and Java Edition particle datapacks:

- Angle-Pinned Spherical Imposters: Bakes discrete yaw/pitch spritesheets across Low, Medium, and High quality tiers for smooth billboard rendering in-game.
- Multi-View TSDF Splat-to-Mesh Bake: Renders 42 Fibonacci-sphere 3DGS RGB-D views, fuses them into a TSDF volume with visual-hull carving, and runs Marching Cubes, QEM decimation, Taubin smoothing, connected-chart UV unwrapping, and visibility-tested texture baking.
- Oriented Splat Clouds & FBX Baking: Supports static quaternion-oriented Gaussian splat entities, 5,000-particle live streams, and high-to-low poly FBX photogrammetry decimation, alongside an interactive browser Imposter Preview Lab.
