**Tulsa Union's Tuttle Stadium** is a social metaverse sports stadium created by the [VAST Lab](/projects?filter=vastlab) and hosted live on [Spatial.io](https://www.spatial.io/s/Tulsa-Unions-Tuttle-Stadium-64bac1f432b4ffa68becfcc9?share=6279006230809640245). As lead developer, I engineered the gameplay systems, multi-user minigames, network synchronization, and dynamic lighting pipelines.

### Environment Lighting & Real-Time Time-of-Day

The stadium environment (modeled by [Chris Gauthier](https://www.artstation.com/chrisgauthier)) features a hybrid lighting architecture: baked occlusion maps for complex stadium seating, faked volumetric light shafts using geometry cones, and dynamic directional lights synchronized to actual Tulsa, Oklahoma real-time sunset/sunrise intervals.

### Networked Minigame Logic

To maximize accessibility across web browsers, game mechanics were architected with state machines managing automated match lifecycles, networked score replication, and dynamic LED jumbotron high scoreboards.
