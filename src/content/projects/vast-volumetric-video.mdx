Developed at the [VAST Lab](/projects?filter=vastlab), this initiative evolves from earlier Python/Unity volumetric prototypes ([`VolumetricVideo`](https://github.com/VAST-Lab/VolumetricVideo)) into our current in-development production stack: a native C++20 multi-camera capture and reconstruction engine ([`volumetric-studio`](https://github.com/VAST-Lab/volumetric-studio)) paired with a Unity 6 WebGPU playback package ([`vast-volumetricvideo-renderer`](https://github.com/VAST-Lab/vast-volumetricvideo-renderer)).

### Current Solution in Development: Volumetric Studio (`volumetric-studio`)

[`volumetric-studio`](https://github.com/VAST-Lab/volumetric-studio) (`volstream.exe`) is a native **C++20** real-time 4D volumetric capture, calibration, reconstruction, and streaming engine with dual GPU compute backends (**CUDA** and **Vulkan via Slang/SPIR-V**) and zero Python/PyTorch runtime dependencies:

- **Deterministic Memory & Multi-Sensor Capture**: Uses pre-allocated `ArenaPool` slabs and lock-free `RingBuffer` queues for zero steady-state heap allocations across **Orbbec SDK v2** RGB-D sensors (Femto Bolt rigs with 8-pin hardware sync and pinhole D2C), UVC webcams, and a raytraced `MockSensor` simulator.
- **Automated Multi-Camera Calibration (`SyncCameras`, `DriftTracker`)**: Detects concentric coded markers and `ALIKED` / LightGlue features, solves `SE3` alignment via Kabsch SVD + Levenberg-Marquardt point-to-plane ICP, and tracks per-frame drift recovery.
- **Foreground Matting & Reconstruction**: Combines `DepthBoxFilter`, `BgSubtractor`, and BiRefNet / SAM-tiny `LearnedMatting` with `RealtimeSplatEngine` (3DGS), `TsdfMeshEngine` (Marching Cubes), and `VolumeCodec` (Morton 16-bit quantization + LZ4/Zstd `.volrec`).
- **Web Control Center & WASM Viewer**: Hosts a browser control dashboard (`localhost:8080`) and a **WebGL2 + WebWorker + WASM** live client (`viewer/`).

### Current Unity 6 Playback Package (`vast-volumetricvideo-renderer` v3.0.4)

[`vast-volumetricvideo-renderer`](https://github.com/VAST-Lab/vast-volumetricvideo-renderer) is a **Unity 6 (`6000.6+`)** UPM package supporting **Built-in RP**, **URP 17**, **HDRP 17**, and **WebGPU** across desktop and browser deployments:

- **`.4dgs` Temporal GOP Compression (`GaussianSplat4DPlayer`)**: Combines SPZ v4 keyframes with Burst-compiled `int16` position and quaternion deltas (15x–40x compression at 30 FPS) and performs in-place GPU buffer updates with zero per-frame `GraphicsBuffer` reallocation.
- **MP4 Video-Texture Splatting (`GaussianSplatVideoPlayer`)**: Samples 4-quadrant video atlases directly inside a compute shader (`CSDecodeVideoSplats`), leveraging native browser H.264/VP9/AV1 hardware decoding on WebGPU.
- **Subgroup-Free WebGPU Radix Sort & Stochastic Accumulation**: Pairs wave-intrinsic desktop sorting (`DeviceRadixSort.hlsl`) with a subgroup-free compute radix sort (`WebGpuRadixSort.hlsl`), multi-threaded WASM CPU octree sorting fallback, and SteadySplats reprojected temporal accumulation (`GaussianSplatTemporalAccumulator`).
- **Live Binary WebSocket Streaming (`GaussianSplatStreamReceiver`)**: Streams live volumetric frames over the `"SGST"` protocol from Unity Editor or Python servers to desktop and WebGPU clients, with unified global sorting alongside 3D meshes and static 3DGS rooms.

### Previous Volumetric Video Attempts & Prototypes (`VolumetricVideo`)

Prior to building the native C++20 studio engine and Unity 6 UPM renderer, earlier lab prototypes in [`VolumetricVideo`](https://github.com/VAST-Lab/VolumetricVideo) explored several foundational approaches:

- **Python Orbbec Live Streaming (`Camera Streaming/unitystreamer.py`)**: Prototype Python capture scripts using `PyOrbbec`, OpenCV, and NumPy to stream depth and RGB point clouds into a Unity receiver (`Realtime Streaming`).
- **Image-Atlas Splat Compression (`Compress to Images/plycompress.py`)**: Experiments converting `.ply` and `.splat` point clouds into compact PNG/TIFF image sets encoding position, rotation, scale, and color for lightweight web streaming.
- **Prototype Unity 2021.3 Compute Renderer (`Unity GS Renderer`)**: Custom compute-shader distance sorting and rasterization in Unity 2021.3 (including Spatial SDK projection adjustments) alongside cross-API reference studies (`Example GS Scripts`) across WebGL, WebGPU, Metal, OpenGL, and Rust.
