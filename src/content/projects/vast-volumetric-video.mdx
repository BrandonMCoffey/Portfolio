Developed at the [VAST Lab](/projects?filter=vastlab), this initiative evolves from earlier Python and Unity volumetric prototypes ([VolumetricVideo](https://github.com/VAST-Lab/VolumetricVideo)) into our current in-development production stack: a native C++20 multi-camera capture and reconstruction engine ([volumetric-studio](https://github.com/VAST-Lab/volumetric-studio)) paired with a Unity 6 WebGPU playback package ([vast-volumetricvideo-renderer](https://github.com/VAST-Lab/vast-volumetricvideo-renderer)).

### Current Solution in Development: Volumetric Studio

[volumetric-studio](https://github.com/VAST-Lab/volumetric-studio) is a native C++20 real-time 4D volumetric capture, calibration, reconstruction, and streaming engine with dual GPU compute backends (CUDA and Vulkan via Slang/SPIR-V) and zero Python/PyTorch runtime dependencies:

- Deterministic Memory & Multi-Sensor Capture: Uses pre-allocated memory arenas and lock-free ring buffers for zero steady-state heap allocations across Orbbec SDK v2 RGB-D sensors (Femto Bolt rigs with 8-pin hardware sync), UVC webcams, and a raytraced mock rig simulator.
- Automated Multi-Camera Calibration: Detects concentric coded markers and learned visual features, solves 3D alignment via Kabsch SVD and Levenberg-Marquardt point-to-plane ICP, and tracks per-frame drift recovery.
- Foreground Matting & Reconstruction: Combines depth bounds filtering, background subtraction, and BiRefNet / SAM-tiny learned matting with real-time 3D Gaussian Splatting, watertight Marching Cubes TSDF meshing, and Morton-quantized LZ4/Zstd compression.
- Web Control Center & WASM Viewer: Hosts a browser control dashboard alongside a WebGL2, WebWorker, and WebAssembly live viewer.

### Current Unity 6 Playback Package

[vast-volumetricvideo-renderer](https://github.com/VAST-Lab/vast-volumetricvideo-renderer) is a Unity 6 UPM package supporting Built-in RP, URP, HDRP, and WebGPU across desktop and browser deployments:

- Temporal GOP Delta Compression: Combines SPZ v4 keyframes with Burst-compiled delta frames (15x–40x compression at 30 FPS) and performs in-place GPU buffer updates with zero per-frame buffer reallocation.
- MP4 Video-Texture Splatting: Samples 4-quadrant video atlases directly inside a compute shader, leveraging native browser H.264/VP9/AV1 hardware decoding on WebGPU.
- Subgroup-Free WebGPU Radix Sort & Stochastic Accumulation: Pairs wave-intrinsic desktop sorting with a subgroup-free compute radix sort for WebGPU, multi-threaded WASM CPU octree sorting fallback, and SteadySplats reprojected temporal accumulation.
- Live Binary WebSocket Streaming: Streams live volumetric frames from Unity Editor or Python servers to desktop and WebGPU clients, with unified global sorting alongside 3D meshes and static 3DGS environments.

### Previous Volumetric Video Attempts & Prototypes

Prior to building the native C++20 studio engine and Unity 6 UPM renderer, earlier lab prototypes in [VolumetricVideo](https://github.com/VAST-Lab/VolumetricVideo) explored several foundational approaches:

- Python Orbbec Live Streaming: Prototype Python capture scripts using PyOrbbec, OpenCV, and NumPy to stream depth and RGB point clouds into a Unity receiver.
- Image-Atlas Splat Compression: Experiments converting `.ply` and `.splat` point clouds into compact PNG and TIFF image sets encoding position, rotation, scale, and color for lightweight web streaming.
- Prototype Unity 2021.3 Compute Renderer: Custom compute-shader distance sorting and rasterization in Unity 2021.3 (including Spatial SDK projection adjustments) alongside cross-API reference studies across WebGL, WebGPU, Metal, OpenGL, and Rust.
