# Brandon Coffey - Portfolio & Cookbook

Personal portfolio website and interactive family cookbook for Brandon Coffey ([brandoncoffey.com](https://brandoncoffey.com)).

## Engine & Tech Stack
- **Framework:** Astro 7
- **UI & Components:** React 19, Tailwind CSS v4, Lucide Icons
- **Content:** MDX (Markdown + JSX) content collections

## Major Features & Sections
- **Projects Showcase:** Interactive portfolio pages covering games, VR/AR simulations, technical art tools, and research lab projects.
- **Academic & Professional CV:** Interactive CV tracking publications, media features, grants, awards, and teaching experience.
- **Family Cookbook (`/cookbook`):** Searchable recipe database with tag filters, favorite saving, interactive recipe views, and shopping list generation.
- **Theme Support:** Dark and light theme modes with responsive mobile-friendly layouts.

## Development
```sh
npm install
npm run dev
npm run build
```
